# Grande Studio — Udhëzues i Shpejtë për Upload në GitHub & Render.com

## Skedarët e përfshirë në këtë paketë:
1. `app.py` — Aplikacioni kryesor i kompletuar (SEO, PWA, iPhone & Samsung, Admin Panel, Push Notifications).
2. `requirements.txt` — Libraritë e nevojshme Python që Render i instalon automatikisht.
3. `Procfile` — Komanda e nisjes së serverit në Render.
4. `render.yaml` — Konfigurimi automatik i shërbimit për Render.com.

## Hapat për publikim:
1. Çzipo (Extract) këtë dosje në kompjuter.
2. (Opsionale) Nëse i ke fotot `thonjët.jpg` ose foton e profilit të Instagramit, vendosi në të njëjtën dosje me `app.py`.
3. Krijo një Repository të ri në **GitHub** dhe bëj upload të gjithë këta skedarë.
4. Hyr në **Render.com** -> **New +** -> **Web Service** -> zgjidh repository-n e GitHub-it dhe shtyp **Create Web Service**.
5. Pas disa minutash do të marrësh linkun publik `https://grande-studio-xxxx.onrender.com` të gatshëm për klientet dhe Google!
